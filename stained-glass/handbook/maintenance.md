# 🧹 Maintenance & Closing

## Member Responsibilities
* **Dust Control:** Wet-wipe surfaces to prevent spreading glass powder. **No dry sweeping.**
* **Soldering Irons:** Ensure irons are turned off and unplugged.
* **Consumables:** Use only what you need and notify the Manager when supplies run low.

### 🗑️ Glass Disposal
1. When the glass box is full, **tape it securely shut**.
2. Place the sealed box in the garbage (loose glass must never go into garbage bags).
3. Replace with a new box from the recycling bin and label it.

## ✅ Closing Checklist
- [ ] Soldering iron unplugged.
- [ ] All tools put away.
- [ ] Project board and glass stored.
- [ ] Grinders cleaned; surrounding surfaces wiped.
- [ ] Work area swept; floor mopped with Swiffer if needed.
- [ ] Lights turned off.
